# 首页浏览器标签名称修改

## 目标

将首页浏览器标签名称从“李彬 · 作品集”修改为“李彬 · 个人网站”。

## 修改范围

- 仅修改 `index.html` 中的静态 `<title>` 文本。
- 不修改首页可见内容、样式、交互或资源。
- 不修改 `about.html`、`category.html`、`project.html` 等其他页面的标题。

## 实现方式

把 `index.html` 的 `<title>李彬 · 作品集</title>` 替换为 `<title>李彬 · 个人网站</title>`。不增加 JavaScript 动态覆盖逻辑。

## 验证

1. 检查首页 HTML 只有一个 `<title>`，且内容准确为“李彬 · 个人网站”。
2. 启动本地静态网站并读取首页，确认返回的页面标题正确。
3. 检查 Git 差异，确认未修改其他页面或功能。
